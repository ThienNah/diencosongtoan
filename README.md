# Vanilla JS Smart Search Component

A fast, lightweight, and responsive search bar component built entirely with Vanilla JavaScript to help users filter dynamic data arrays in real-time.

## 🔥 Features
- **Live Search (Real-time):** Instant results display as you type using JavaScript input events.
- **Vietnamese Accent Removal:** Standardizes inputs (e.g., "may bom" or "máy bơm") for accurate data filtering.
- **Hyperlink Navigation:** Direct integration with custom data object links for smooth navigation.

## 🛠️ Tech Stack
- HTML5 / CSS3
- Pure JavaScript (Vanilla JS)

## 🚀 How it works
The project showcases how to handle dynamic data filtering (`Array.prototype.filter()`) and DOM manipulation directly via JavaScript without using any heavy frameworks. This is a personal portfolio component created for open-source reference.
