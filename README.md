# Electric Song Toan - Smart Search Component

A fast, lightweight, and responsive search bar built entirely with **Vanilla JavaScript** to help users easily look up electrical repair services and products.

## 🔥 Features
- **Live Search (Real-time):** Instant results display as you type using JavaScript input events.
- **Vietnamese Accent Removal:** Standardizes inputs (e.g., "may bom" or "máy bơm") for accurate filtering.
- **Hyperlink Navigation:** Direct integration with catalog links for smooth user onboarding.

## 🛠️ Tech Stack
- HTML5 / CSS3
- Pure JavaScript (Vanilla JS)

## 🚀 How it works
The project showcases how to handle dynamic data filtering (`Array.prototype.filter()`) and DOM manipulation directly via JS without any heavy frameworks.
